# weather
My solution for the [Weather App](https://www.theodinproject.com/lessons/node-path-javascript-weather-app) project as part of the Javascript course from The Odin Project. 

## link
[Don't want to look outside? You can check the weather here](https://jshuhler.github.io/weather-app/).

## features
- Basic weather data for today and tomorrow via the public Visual Crossing Weather API.
- Error handling for possible HTTP status codes returned by the API.
- Easy switching between temperature units.

## skills used and challenges
- This was the curriculum's first project using promising and asychronous functions to fetch data from an API as well as try/catch blocks for error handling.
- Using dynamic imports to display weather icons.
- I consciously decided to keep an extremely minimal styling theme and not use the user's current location on load to display the weather and instead display the absolute minimum to use the app - a search bar and temperature unit toggle.
